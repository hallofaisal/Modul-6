#### 2.1 Version Control System
Ditulis oleh: Faisal rizky (301220037)

Version Control System (VCS) adalah sistem yang mencatat perubahan pada file atau kumpulan file selama waktu tertentu sehingga pengguna dapat mengingat versi tertentu di kemudian hari. Terdapat dua jenis VCS:

1. **Centralized VCS**: Memiliki satu server sentral yang menyimpan semua versi file
2. **Distributed VCS**: Setiap pengguna memiliki salinan lengkap repository

#### 2.2 Git
Ditulis oleh: [Nama Lengkap Anda] (301220037)

Git adalah distributed version control system yang dibuat oleh Linus Torvalds pada tahun 2005. Keunggulan Git:

- **Kecepatan**: Operasi dilakukan secara lokal
- **Integritas Data**: Menggunakan checksum untuk semua data
- **Branching Murah**: Membuat branch baru sangat cepat dan efisien

 2.3 GitHub


GitHub adalah layanan hosting untuk repository Git yang menyediakan fitur kolaborasi seperti:
- Pull Request
- Issue Tracking
- GitHub Actions (CI/CD)
- Project Management
